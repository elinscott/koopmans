######################
 Dielectric constants
######################

The macroscopic dielectric constant of a semiconductor, computed with the ``dft_eps``
task, and then handed to a Koopmans calculation as ``eps_inf``. The tutorial explains
why a Koopmans calculation on a solid wants that number in the first place, and what
happens to the band structure if you get it wrong.
