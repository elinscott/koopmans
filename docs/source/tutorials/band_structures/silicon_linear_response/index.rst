 The band structure of silicon, from linear response
#####################################################

The same silicon band structure as the previous tutorial, with the screening parameters
obtained from density-functional perturbation theory in the primitive cell instead of
from a supercell. The point is the comparison: the same physics, at a very different
cost, and the reader should finish knowing which route to reach for.
