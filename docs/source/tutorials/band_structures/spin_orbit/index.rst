##########################################
 Band structures with spin-orbit coupling
##########################################

A KI band structure computed with spin-orbit coupling, using the spinor formulation of
the linear-response route. The tutorial also has to be plain about the constraints: the
noncollinear implementation supports only the local-density approximation as its base
functional, and needs full-relativistic pseudopotentials, which means assembling a
pseudopotential family by hand rather than installing one.

.. note::

    This tutorial has not been written yet. It is tracked by `issue #68
    <https://github.com/elinscott/koopmans/issues/68>`_.
